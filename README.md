# Klasifikasi-Citra-Emosi-Wajah-Menggunakan-CNN
Klasifikasi Citra Emosi Wajah Menggunakan CNN merupakan implementasi Deep Learning untuk mengenali dan mengklasifikasikan emosi berdasarkan citra ekspresi wajah. Model Convolutional Neural Network (CNN) digunakan untuk mempelajari pola visual pada gambar dan mengidentifikasi berbagai kategori emosi secara otomatis.
